# Progressing App - Desktop Tool  - Müəyyən zaman aralığı üçün Maliyyə və Məhsuldarlıq İdarəetmə Proqramı

## Xüsusiyyətlər
 Gəlir/Xərc idarəetməsi
 Vizual statistika (matplotlib ilə)
 Ödəmə tarixçəsi
 Fəaliyyət kontrolu (3 fərqli pəncərə)
 Real-vaxt hesabat
 Azərbaycan dilində interfeys


## Lisenziya və Məsuliyyət

Bu proqram **LGPL v3** lisenziyası altında paylaşılır. 


## Texnologiyalar
 Python 3.9+
 PySide6 (Qt6)
 Matplotlib
 python-docx


## Ümumi baxış

Şəxsi ehtiyacım səbəiylə özümçün hazırlamağa çalışdığım bir idea idi, sonradan müəyyən özəlləşdirilə bilən funksiyalar əlavə edib açıq mənbə kodları ilə yayımlamaq qərarı aldım. Həyatnızda hansısa zaman aralığını kontrol etmək, fəaliyyətinizin dinamikasını statistik olaraq görə bilməyiniz üçün bir vasitə ola bilər. Bcardıqca interfeysi və funksiyonallığı daha da zənginləşdirməyə çalışacam. Əsas məqsəd odur kii, tək bir pəncərədə müəyyən etmiş olduğunuz zaman kəsiyindəki irəliləmə yaxud gedişatınızı görə biləsiniz. Buranı oxuduğunuz üçün xüsusi təşəkkür və böyük ehtimal ki siz də program inkişaf etdirməyə maraqlı birisiniz, böyük ehtimalki də bu sahədə məndən daha peşəkarsız. O səbəblə sizdən də hər hansısa bir dəyişiklik yaxud funksiyonal ideya tövhəsi görmək çox məmnun edərdi. Uğurlar.
